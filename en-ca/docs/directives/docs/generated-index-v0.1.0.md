# Docs: Generated Index

Version: 0.1.0
Status: In force

## Rule

`{language}/docs/README.md` lists every document under `{language}/docs/`, section by section, with its title, version and status from its front matter. It is generated by `uc-automa docs index`, begins with a comment saying so, and is never edited by hand. It takes its creator and rights from the repository's SAT sidecar.

## Rationale

This is decision D9, recorded as uc-automa 0009. A hand-kept index drifts from the documents it lists; a generated one cannot.

## Check

`conformance.docs.generated_index` generates the index and compares it with the file. Its fixtures are under `tests/fixtures/conformance/docs/generated-index/`.
