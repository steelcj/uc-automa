# Decision: Generated Documentation Index

Version: 0.1.0
Status: Accepted

## Context

The foundation brief <a id="cite-steel-2026b"></a>[(Steel, 2026b)](#ref-steel-2026b) left this open as D9, recommended but not confirmed. Christopher Steel confirmed it on 2026-10-09.

## Decision

`{language}/docs/README.md` is generated by `uc-automa docs index`. It lists every document, section by section, with its title, version and status, taken from front matter. It begins with a comment marking it as generated, and is never edited by hand.

## Consequences

- The directive `docs/generated-index` and its check keep the index current.
- The index takes its creator and rights from the repository's SAT sidecar, so it carries a correct License section without a template.
