# Decision: Names

Version: 0.1.0
Status: Accepted

## Context

The new automa needed a name for its repository, package, command and files. A bare name such as automa invites collisions with other packages and commands. The decision was worked out with Christopher Steel on 2026-10-07 and 2026-10-09 and recorded in the foundation brief <a id="cite-steel-2026b"></a>[(Steel, 2026b)](#ref-steel-2026b).

## Decision

| Thing | Name |
| --- | --- |
| Repository | `uc-automa` |
| Python package | `uc_automa` |
| Command | `uc-automa` |
| Consumer file | `.uc-automa.yaml` |
| Sidecar | `.uc-automa.assets/` |

The name pairs with uc-radar and is distinctive enough to avoid collisions.

## Consequences

- Placeholder names in earlier drafts, such as `automa`, `.automa.yaml` and `automa-ceremony`, are superseded.
- Every repository names its own sidecar for itself, as uc-automa does (uc-automa 0022).
